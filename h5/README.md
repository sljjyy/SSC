# 小说创作助手 - H5版

这是小说创作助手的H5版本，为手机用户提供便捷的网络文学创作工具。

## 功能特点

- **七步创作流程**：选题 → 人物设定 → 粗纲 → 细纲 → 正文 → 标题 → 导语
- **多平台支持**：支持OpenAI、硅基流动、Deepseek等多种AI平台
- **响应式设计**：针对手机屏幕进行优化，提供良好的移动端体验
- **离线保存**：使用localStorage保存创作进度，防止意外丢失
- **自定义配置**：支持API密钥配置、平台选择和模型设置
- **模拟模式**：开发环境下支持模拟API调用，无需真实API密钥

## 快速开始

1. 将`h5`目录复制到您的Web服务器上
2. 在浏览器中访问`index.html`文件
3. 点击"配置"按钮，设置您的API密钥
4. 开始七步创作流程

## 配置说明

### API密钥配置

H5版本支持三种AI平台的API密钥配置：
- OpenAI：用于调用OpenAI的GPT系列模型
- 硅基流动：用于调用各种开源模型
- Deepseek：用于调用DeepSeek的模型

在应用界面点击右上角的"配置"按钮，输入您的API密钥。

### 平台和模型选择

根据不同的创作步骤，系统会自动选择合适的平台和模型：
- 步骤1-4：默认使用硅基流动的[16]千问或[4]腾讯混元模型
- 步骤5-6：默认使用硅基流动的[4]千问长文模型
- 步骤7：默认使用硅基流动的[16]千问模型

您可以在配置界面自定义每个步骤的平台和模型。

## 使用指南

### 创作流程

1. **步骤1：设置参数**
   - 选择故事类型、困境类型、投稿平台
   - 选择情绪类型
   - 输入灵感（可选）
   - 点击"开始生成"按钮

2. **步骤2：选题**
   - 查看系统生成的故事选题
   - 可以修改选题内容或点击"重新生成"按钮
   - 确认后点击"下一步"按钮

3. **步骤3：人物设定**
   - 查看系统生成的主角、反派和配角设定
   - 可以修改设定内容或点击"重新生成"按钮
   - 确认后点击"下一步"按钮

4. **步骤4：粗纲**
   - 查看系统生成的故事粗纲
   - 可以修改粗纲内容或点击"重新生成"按钮
   - 确认后点击"下一步"按钮

5. **步骤5：细纲**
   - 查看系统生成的故事细纲
   - 可以修改细纲内容或点击"重新生成"按钮
   - 确认后点击"下一步"按钮

6. **步骤6：正文**
   - 查看系统生成的故事正文
   - 可以修改正文内容或点击"重新生成"按钮
   - 确认后点击"下一步"按钮

7. **步骤7：标题和导语**
   - 查看系统生成的标题和导语
   - 可以修改标题和导语内容或点击"重新生成"按钮
   - 完成创作

### 快捷键

- 点击顶部导航栏可以快速跳转到不同的创作步骤
- 每个步骤都有"重新生成"按钮，可以重新生成当前内容
- 每个步骤都有"保存"按钮，可以手动保存当前进度

## 注意事项

- 请妥善保管您的API密钥，不要泄露给他人
- 部分AI平台可能有使用限制或计费规则，请参考各平台的官方文档
- 创作内容保存在浏览器的localStorage中，清除浏览器数据可能会导致内容丢失
- 对于大型创作项目，建议定期导出和备份您的创作内容

## 常见问题

### Q: 为什么生成内容失败？
A: 可能的原因包括API密钥错误、网络问题、API调用限制等。请检查您的API密钥配置，并确保网络连接正常。

### Q: 创作内容可以导出吗？
A: 目前版本暂不支持直接导出功能，但您可以手动复制各步骤的内容。

### Q: 支持哪些浏览器？
A: 建议使用最新版的Chrome、Firefox、Safari或Edge浏览器。
